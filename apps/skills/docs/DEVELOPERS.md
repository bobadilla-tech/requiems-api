# Developer Note

Full spec and architecture: [DESIGN.md](DESIGN.md). The generalized pipeline
pattern, if you're adapting this for another API:
[HOW_TO_BUILD_AGENT_SKILLS.md](HOW_TO_BUILD_AGENT_SKILLS.md).

This package lives in the `requiems-api` monorepo (`apps/skills`). Skills are
regenerated by `.github/workflows/release-sync.yml` whenever a release is
published: if the output changed, it opens a PR with a patch version bump, and
merging that PR runs `.github/workflows/publish-skills.yml` (npm publish).

To regenerate skills locally:

```bash
# from apps/skills
node scripts/build/index.ts --source ../dashboard/config/api_docs --output ./skills
```
